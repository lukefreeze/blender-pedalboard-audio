VST3 Plugin Folder
==================
Drop any VST3 plugin files here to use them in the Pedalboard rack.

Recommended free VST3 plugins to get started:

Dragonfly Reverb (reverb)
  https://github.com/michaelwillis/dragonfly-reverb/releases

Vital (synth/effects)  
  https://vital.audio

Surge XT (synth/effects)
  https://surge-synthesizer.github.io

After dropping a .vst3 file here, reload the Pedalboard addon
in Blender (F8) and it will appear in the Add Rack Effect menu.
